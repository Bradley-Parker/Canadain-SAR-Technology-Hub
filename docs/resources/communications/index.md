# Communications Resources

This section covers hardware, frequencies, satellite protocols, and field networking for search and rescue operations.

## Subcategories & Focus Areas

- **Satellite Messengers**: Garmin inReach, ZOLEO, Starlink field deployments, tracking feeds
- **Mesh & Field Networks**: Meshtastic, portable WiFi links for ICP (Incident Command Post)
