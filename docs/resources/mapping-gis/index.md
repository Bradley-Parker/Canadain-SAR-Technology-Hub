# Mapping & GIS Resources

This section contains operational templates, workflows, and standards for search and rescue geospatial technologies.

---

## Subcategories & Focus Areas
- **Web & Mobile Mapping**: SARTopo / CalTopo, Avenza Maps, SARMap
- **Desktop GIS**: QGIS workflows, offline tile generation, digital elevation models (DEM)
- **Field Navigation**: Garmin GPS configurations, datum (NAD83 / WGS84) and coordinate system (UTM / Lat-Long) standards
- **Geodata Overlays**: Province-wide grid systems, jurisdictional boundaries, trail networks
