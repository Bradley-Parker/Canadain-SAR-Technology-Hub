# Operational File Downloads

The Canadian SAR Technology Hub maintains a central library of field-ready files, templates, and profiles for ground search and rescue operations. These resources are designed to be imported directly into incident command systems, mapping software, and field devices.

Supporting files are also linked directly within their respective guides across the **[Resources](../index.md#resource-categories)** section.

---

## File Categories

### Geospatial Data
*Standard geodata layers, search grids, jurisdictional boundaries, and assignment shapes.*

- **Formats**: `.geojson`, `.gpx`, `.kml`, `.kmz`
- **Compatible Software & Hardware**: CalTopo / SARTopo, Garmin BaseCamp, handheld GPS units, QGIS, Avenza Maps

### Operational Forms & Incident Templates
*Printable and fillable documents for incident command posts and field search teams.*

- **Formats**: `.pdf`, `.docx`, `.xlsx`
- **Included Resources**: Incident action plans, search briefing sheets, debrief records, lost person questionnaires, medical packaging checklists

### Device Configurations & Codeplugs
*Configuration profiles and presets for field radios, tracking devices, and field software.*

- **Formats**: `.json`, `.xml`, `.dat`, `.csv`
- **Included Resources**: Mutual-aid radio channel codeplugs, GPS profile configs, software display layouts
